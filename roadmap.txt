================================================================================
                    ZEETUBE - 8-STEP MASTER ROADMAP (A TO Z)
             100% YouTube 1:1 UI Clone | Privacy-First (No History)
================================================================================

PROJECT PHILOSOPHY:
1. Zero History & Zero Tracking: Koi watch history, search history, ya telemetry save nahi hogi. 100% private.
2. 1:1 YouTube UI Replica: Color schemes, typography, layout, icons, video player, channel page bilkul original YouTube jaisa lagega.
3. Pure Flutter Frontend: Koi server/database nahi chalana. Piped API public endpoints + local shared_preferences for subscriptions.

--------------------------------------------------------------------------------

--------------------------------------------------------------------------------
STEP 2: PIPED API RESILIENT SERVICE LAYER
--------------------------------------------------------------------------------
- Multi-Instance Fallback Mechanism:
  Agar ek instance busy ho to app automatically doosre par switch ho jaye:
  1. https://pipedapi.kavin.rocks
  2. https://api.piped.private.coffee
  3. https://piped-api.lunar.icu
- Core Endpoints Integration:
  * GET /trending?region=US (Home trending feed)
  * GET /search?q={query}&filter=all (Search videos/channels)
  * GET /streams/{videoId} (Direct MP4/HLS streaming urls, title, channel info, related videos)
  * GET /channel/{channelId} (Channel avatar, banner, subscriber count, and latest uploaded videos)

--------------------------------------------------------------------------------
STEP 3: 100% PRIVACY & LOCAL SUBSCRIPTION ENGINE (ZERO HISTORY)
--------------------------------------------------------------------------------
- Strict Privacy Rule:
  * Koi Watch History database ya cache save NAHI hogi.
  * Koi Search Query track ya save NAHI hogi.
- Local Subscriptions Only:
  * 'shared_preferences' mein sirf user ke manually "Subscribe" kiye hue channels save honge:
    { "channelId", "channelName", "avatarUrl", "subscribers" }
  * Zero-Login: User bina kisi Google account ke kisi bhi YouTuber ko Subscribe/Unsubscribe kar sakta hai.
